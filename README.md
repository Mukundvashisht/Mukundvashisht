## A little about me

I'm a developer building web applications and Python utilities. My projects range from React tools and API-driven websites to a Flask application that brings project tracking, administration, and real-time communication together.

- **My recent focus:** [AR Studios](https://github.com/Mukundvashisht/ar_studios), a CRM and project management application.
- **On the frontend:** React, JavaScript, HTML, and CSS for interactive web experiences.
- **Behind the interface:** Python, Flask, PostgreSQL, and Socket.IO for application logic, data, and live updates.
- **Beyond web apps:** practical Python projects, including a desktop assistant and a video downloader.
